# Data access

This repository contains code and aggregate results, not retinal images, participant identifiers, individual predictions, private splits or model binaries.

| Resource | Provider |
|---|---|
| MMRDR | https://doi.org/10.1038/s41597-026-07005-9 |
| EyePACS 2015 competition release | https://www.kaggle.com/c/diabetic-retinopathy-detection/data |
| DeepDRiD | https://doi.org/10.1016/j.patter.2022.100512 |
| Messidor-2 images and examination pairing | https://www.adcis.net/en/third-party/messidor2/ |
| Google Messidor-2 annotations | https://www.kaggle.com/datasets/google-brain/messidor2-dr-grades |

Obtain each resource from its provider and follow its access, use, acknowledgment and redistribution conditions. A paper's license does not automatically govern the dataset, and a software license does not grant permission to redistribute clinical images. Messidor-2 does not supply DR grades in its official pairing table; the cited Google annotations are a separate resource.

Released identifiers support within-release grouping only. They do not prove cross-source patient independence. Original acquisition ethics and any consent waivers belong to the source studies and must not be represented as a new approval for a secondary analysis.
